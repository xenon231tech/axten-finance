# Axten

Axten — personal finance tracker in 14 languages: budgets, wallets, assets & live crypto prices. Free & private, no server needed.

Live: https://axten-xenon231techs-projects.vercel.app/

## Features

- Track income & expenses, budgets, wallets, assets, debts & bills
- Live crypto prices (CoinGecko top 250) + portfolio P/L, 7-day price charts, DCA reminders, price alerts & watchlist
- Crypto converter, CSV import, Excel/JSON/CSV export, receipt photos
- 14 languages, 29 currencies, PIN lock, demo mode, simple mode
- Axten Pro (one-time 100 Telegram Stars): accent themes, unlimited wallets/goals, backup & restore via Telegram, advanced reports & insights
- Donations via Telegram Stars

## Privacy

Your data stays on your device (browser localStorage). No account, no server, no tracking. See [privacy.html](privacy.html) for the full policy.

## Run it

Open `index.html` in a browser, or deploy it to any static host.
